# Resolv — Business Intelligence & Automation Case Study

Portfolio case study describing analytical work with operational data, reporting, integrations, and workflow automation at Resolv.

## Role

**Business Intelligence & Automation Analyst**

## Focus

- Business process and bottleneck analysis
- Data integration across CRM, ERP, payment, and document systems
- SQL-based validation, KPI reporting, and exception monitoring
- Data requirements and decision rules for workflow automation

## Tools

SQL, PostgreSQL, dashboards, data validation, reporting, process mapping
